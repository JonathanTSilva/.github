# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub private vulnerability reporting: open the **Security** tab of the affected repository and choose **Report a vulnerability**, or go to `/security/advisories/new` on that repository.

Do not open a public issue or pull request for a vulnerability, and do not send reports by email.

## What to expect

You can expect a first response within 7 days. After that I will confirm the issue, work on a fix and coordinate disclosure with you.

## Supported versions

Only the latest release of each project receives security fixes, unless the repository states otherwise.
