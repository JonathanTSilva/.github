# Forks

Two kinds, with different rules.

| | Contribution fork | Variant |
|---|---|---|
| Purpose | Send a pull request upstream | Your own version of someone else's project |
| Name | Keeps the upstream name | Renamed into the [naming system](naming.md) |
| Topic | `fork` | The usual `kind-` and `status-` topics |
| Lifetime | Only while the PR is open, deleted after merge | Permanent |
| Pinned | Never | Case by case |
| Upstream link | Stays attached | Detached from upstream (ask GitHub support, or re-create the repo) |
| License | Upstream's | Upstream license and copyright are kept |
| README | Untouched | States the origin in its first lines |

A fork of a public repo cannot be made private. If a variant must stay private, re-create it instead of forking.
